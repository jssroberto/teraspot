' === Frontend & Auth ===
Admin --> Cognito_UP : 1) Authenticate
Cognito_UP --> Admin : 2) JWT (for Admin Ops)
Admin --> Admin_UI : 3) Uses Dashboard
User --> WebApp_UI : 4) Opens Public App (No Auth)

' --- REST Flows ---
WebApp_UI --> APIGW_REST : GET /spaces
APIGW_REST --> APIGW_Authorizer : Validate JWT
APIGW_Authorizer --> Lambda_Read : Authorize
APIGW_REST --> Lambda_Read : Invoke
Lambda_Read --> DDB : Read items
Lambda_Read --> APIGW_REST : JSON
APIGW_REST --> WebApp_UI : Response

' --- WebSocket Flows ---
WebApp_UI --> APIGW_WS : Connect (Public)
Admin_UI --> APIGW_WS : Connect (Admin Events)
APIGW_WS --> Lambda_WS_Connect : $connect
Lambda_WS_Connect --> DDB : Store CID
WebApp_UI --> APIGW_WS : Disconnect
APIGW_WS --> Lambda_WS_Disconnect : $disconnect
Lambda_WS_Disconnect --> DDB : Remove CID

' === Admin / Config Flow ===
Admin_UI --> APIGW_REST : POST /config
APIGW_REST --> Lambda_Config : /config
Lambda_Config --> S3 : Write config.json

' === AI Node & Ingest ===
ECR ..> Containers : Pull Image
Camera_Stream --> Containers : Provide video
Containers --> S3 : Read config.json (AWS SDK)
EC2 --> APIGW_IAM_Auth : IAM Auth for API access
Containers --> EC2 : Inherit instance profile
Containers -up-> IoTCore : Publish status (MQTT)
IoTCore -down-> Lambda_Ingest : IoT Rule triggers
Lambda_Ingest --> DDB : Put/Update item
Lambda_Ingest --> SQS_DLQ : On failure

' === Monitoring ===
Containers --> CloudWatch : Logs
CloudWatch --> SNS : Alarm -> Notification

' === Streams, Analytics, Alerts ===
DDB --> DDB_Stream : Change events
DDB_Stream --> Lambda_Analytics : Trigger
EventBridge --> Lambda_Analytics : Trigger (Every 5m\nHealth Check)
Lambda_Analytics --> Timestream : Write historical data
Lambda_Analytics --> SNS : Publish alerts
Lambda_Analytics --> APIGW_WS : Push Updates to Clients

' === KPI & Commands ===
Admin_UI --> APIGW_REST : GET /kpi
APIGW_REST --> Lambda_KPIMonitor : /kpi
Lambda_KPIMonitor --> DDB : Read aggregated data
Lambda_KPIMonitor --> Timestream : Read historical metrics

Admin_UI --> APIGW_REST : POST /command
APIGW_REST --> Lambda_DeviceCommand : /command
Lambda_DeviceCommand --> IoTCore : Publish command (MQTT)
IoTCore --> Containers : Receive command

' === Admin Notification ===
SNS --> Admin : Notify

@enduml
