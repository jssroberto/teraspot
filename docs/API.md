# TeraSpot API Reference

This document serves as the central entry point and **Single Source of Truth** for the TeraSpot Backend API.

## Base URL

The API is deployed via AWS API Gateway.

- **Development Base URL**: `https://<api-id>.execute-api.us-east-1.amazonaws.com/dev`

The `<api-id>` is a unique identifier generated by AWS. To retrieve your specific Base URL (which contains this ID), run:

```bash
cd infrastructure/terraform && terraform output -raw api_gateway_url
```

## Authentication

- **Current Status**: `NONE` (Open)
- **Future Plan**: JWT Authentication via Amazon Cognito.

## Endpoints

### Configuration Management (`/config`)

The configuration API uses a **Command Pattern** via a single `POST` endpoint. The action to perform is specified in the JSON body.

#### 1. SAVE Configuration

Creates or updates a configuration item.

- **URL**: `/config`
- **Method**: `POST`
- **Content-Type**: `application/json`

**Request Body Schema:**

| Field                | Type    | Required         | Description                                          |
| :------------------- | :------ | :--------------- | :--------------------------------------------------- |
| `action`             | string  | Yes              | Must be `"SAVE"`.                                    |
| `config`             | object  | Yes              | The configuration object to save.                    |
| `config.config_type` | string  | Yes              | One of: `zone`, `device`, `threshold`, `alert_rule`. |
| `config.value`       | object  | Yes              | Type-specific configuration data.                    |
| `config.facility_id` | string  | **Yes** (Zone)   | Required for `zone` type.                            |
| `config.zone_id`     | string  | **Yes** (Zone)   | Required for `zone` type.                            |
| `config.device_id`   | string  | **Yes** (Device) | Required for `device` type.                          |
| `config.spaces`      | array   | No               | (For `zone` only) List of space definitions.         |
| `config.updated_by`  | string  | No               | Defaults to `"system"`.                              |
| `config.active`      | boolean | No               | Defaults to `true`.                                  |

**Example Request (Zone):**

```json
{
  "action": "SAVE",
  "config": {
    "config_type": "zone",
    "facility_id": "facility-01",
    "zone_id": "zone-a",
    "value": {
      "name": "Zone A",
      "total_spaces": 50
    },
    "spaces": [
      {
        "space_id": "A-01",
        "polygon": [
          [100, 100],
          [200, 100],
          [200, 200],
          [100, 200]
        ]
      }
    ]
  }
}
```

**cURL Example:**

```bash
curl -X POST https://<api-id>.execute-api.us-east-1.amazonaws.com/dev/config \
  -H "Content-Type: application/json" \
  -d '{
    "action": "SAVE",
    "config": {
      "config_type": "zone",
      "facility_id": "f1",
      "zone_id": "z1",
      "value": { "name": "Test Zone", "total_spaces": 10 }
    }
  }'
```

**Success Response (200 OK):**

```json
{
  "success": true,
  "message": "Config roi-f1-z1 saved successfully"
}
```

**Error Response (400 Bad Request):**

```json
{
  "error": "zone must have 'facility_id' and 'zone_id'"
}
```

#### 2. GET Configuration

Retrieves a specific configuration by its ID.

- **URL**: `/config`
- **Method**: `POST`

**Request Body Schema:**

| Field       | Type   | Required | Description                              |
| :---------- | :----- | :------- | :--------------------------------------- |
| `action`    | string | Yes      | Must be `"GET"`.                         |
| `config_id` | string | Yes      | The ID of the configuration to retrieve. |

**Example Request:**

```json
{
  "action": "GET",
  "config_id": "roi-facility-01-zone-a"
}
```

**cURL Example:**

```bash
curl -X POST https://<api-id>.execute-api.us-east-1.amazonaws.com/dev/config \
  -H "Content-Type: application/json" \
  -d '{
    "action": "GET",
    "config_id": "roi-facility-01-zone-a"
  }'
```

**Success Response (200 OK):**

```json
{
  "config": {
    "config_id": "roi-facility-01-zone-a",
    "config_type": "zone",
    "facility_id": "facility-01",
    "zone_id": "zone-a",
    "value": { "name": "Zone A", "total_spaces": 50 },
    "spaces": [
      {
        "space_id": "A-01",
        "polygon": [
          [100, 100],
          [200, 100],
          [200, 200],
          [100, 200]
        ]
      }
    ],
    "timestamp": "2025-11-27T10:00:00Z",
    "version": 1,
    "updated_by": "system",
    "active": true
  }
}
```

#### 3. LIST Configurations

Lists all configurations of a specific type.

- **URL**: `/config`
- **Method**: `POST`

**Request Body Schema:**

| Field         | Type   | Required | Description                                 |
| :------------ | :----- | :------- | :------------------------------------------ |
| `action`      | string | Yes      | Must be `"LIST"`.                           |
| `config_type` | string | Yes      | The type of configs to list (e.g., `zone`). |

**Example Request:**

```json
{
  "action": "LIST",
  "config_type": "zone"
}
```

**cURL Example:**

```bash
curl -X POST https://<api-id>.execute-api.us-east-1.amazonaws.com/dev/config \
  -H "Content-Type: application/json" \
  -d '{
    "action": "LIST",
    "config_type": "zone"
  }'
```

**Success Response (200 OK):**

```json
{
  "config_type": "zone",
  "count": 2,
  "items": [
    { "config_id": "zone-a", ... },
    { "config_id": "zone-b", ... }
  ]
}
```

## Data Schemas

### Zone Object (`value`)

| Field          | Type   | Description                                  |
| :------------- | :----- | :------------------------------------------- |
| `name`         | string | Human-readable name of the zone.             |
| `total_spaces` | number | Total number of parking spaces in this zone. |

### Device Object (`value`)

| Field  | Type   | Description                             |
| :----- | :----- | :-------------------------------------- |
| `ip`   | string | IP address of the device (camera/node). |
| `port` | number | Port number.                            |

### Space Object (in `spaces` list)

| Field      | Type   | Description                                    |
| :--------- | :----- | :--------------------------------------------- |
| `space_id` | string | Unique ID for the space (e.g., `A-01`).        |
| `polygon`  | array  | List of `[x, y]` coordinates defining the ROI. |
